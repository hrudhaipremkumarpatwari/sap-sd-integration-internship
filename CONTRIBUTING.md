# Working in this repository

This is a documentation portfolio. Keep project artifacts accurate, traceable, and clear about their evidence status.

## Conventions

- Follow the folder structure and the [report template](docs/report-template.md).
- Use descriptive lowercase folder and file names; avoid spaces in filenames.
- Include source citations for researched claims and record access dates for web references.
- Label estimates, assumptions, proposed designs, illustrative examples, and simulated outcomes where they appear.
- Use only synthetic example records and never add credentials, personal data, or confidential materials.
- Keep editable diagram sources with their exported images.
- Update the relevant week README and this project’s status when deliverables are actually completed.

## Review before submission

Check task coverage, internal consistency across weeks, citation quality, evidence labels, accessibility/readability, and the final Word rendering. A repository review does not establish that a system was accessed or a test was executed.
