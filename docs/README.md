# Shared documentation

Use this folder for project-wide conventions that apply across all four reports.

- [Assumptions and glossary](assumptions-and-glossary.md): working case boundaries and consistent terminology.
- [Report template](report-template.md): reusable outline for the four DOCX submissions.

Store source citations in `shared/references/`. Keep week-specific decisions in that week’s folder, then update the shared assumptions if the decision affects later deliverables.
